## 소개

띵타이쿤 일꾼용은 반복적인 마우스 클릭 작업을 자동화하고, 마우스 및 키보드 동작을 녹화하여 재생할 수 있는 유틸리티 애플리케이션입니다. CustomTkinter를 사용한 현대적인 GUI를 제공하며, 단축키를 통한 빠른 제어를 지원합니다.

## 주요 기능

### 자동 클릭 (오토마우스)
- **반복 클릭**: 설정한 간격으로 자동 클릭
- **꾹누르기**: 마우스 버튼을 계속 누르고 있는 상태 유지
- **좌클릭/우클릭** 지원
- **랜덤 변동값**: 클릭 간격에 랜덤성을 추가하여 자연스러운 동작 구현
- **단축키 제어**: F6(시작), F7(중지) 기본 단축키 지원

### 매크로 녹화 및 재생
- **동작 녹화**: 마우스 클릭, 이동, 스크롤 및 키보드 입력 녹화
- **재생 옵션**:
  - 반복 모드: 1회, 지정 횟수, 무한 반복
  - 재생 속도: 0.5x, 1x, 2x, 4x
- **파일 저장/불러오기**: 매크로를 파일로 저장하고 불러올 수 있음
- **단축키 제어**: F8(녹화), F9(재생), F10(중지) 기본 단축키 지원

### 설정
- **단축키 커스터마이징**: 모든 단축키를 사용자 정의 가능
- **랜덤 변동값 설정**: 자동 클릭의 자연스러움 조절
- **테마 모드**: 다크 모드 / 라이트 모드 전환
- **자동 업데이트**: 새 버전 확인 및 다운로드

### 띵타이쿤 정보
- 게임 관련 정보 제공

## 시스템 요구사항

- **운영체제**: Windows 10 이상
- **Python**: 3.8 이상 (개발 환경)
- **권한**: 관리자 권한이 필요할 수 있음 (글로벌 단축키 사용 시)

## 설치 방법

### 방법 1: 실행 파일 사용 (권장)

1. [릴리스 페이지](https://github.com/jaeuk9060/dding_mecro/releases)에서 최신 버전 다운로드
2. 실행 파일(`.exe`)을 실행

### 방법 2: 소스 코드에서 실행

1. 저장소 클론:
```bash
git clone https://github.com/jaeuk9060/dding_mecro.git
cd dding_mecro
```

2. 가상 환경 생성 및 활성화 (선택사항):
```bash
python -m venv venv
venv\Scripts\activate  # Windows
```

3. 의존성 설치:
```bash
pip install -r requirements.txt
```

4. 애플리케이션 실행:
```bash
python main.py
```

또는

```bash
python -m autoclicker
```

## 사용 방법

### 자동 클릭 사용하기

1. 애플리케이션 실행
2. **오토마우스** 메뉴 선택
3. 클릭 타입 선택 (좌클릭/우클릭)
4. 클릭 모드 선택:
   - **반복**: 설정한 간격으로 반복 클릭
   - **꾹누르기**: 버튼을 계속 누르고 있음
5. 반복 모드인 경우 클릭 간격(초) 입력
6. **시작** 버튼 클릭 또는 F6 키 누르기
7. **중지** 버튼 클릭 또는 F7 키 누르기

### 매크로 사용하기

1. **매크로** 메뉴 선택
2. **녹화 시작** 버튼 클릭 또는 F8 키 누르기
3. 원하는 동작 수행 (마우스 클릭, 키보드 입력 등)
4. **녹화 중지** 버튼 클릭 또는 F8 키 다시 누르기
5. 재생 옵션 설정:
   - 반복 모드 선택
   - 재생 속도 선택
6. **재생 시작** 버튼 클릭 또는 F9 키 누르기
7. **재생 중지** 버튼 클릭 또는 F10 키 누르기

### 설정 변경하기

1. 상단 우측의 **⚙️** 버튼 클릭
2. 원하는 설정 변경:
   - 단축키: 버튼을 클릭하고 원하는 키를 누르기
   - 랜덤 변동값: ON/OFF 및 값 설정
   - 테마 모드: 다크/라이트 모드 선택
3. **저장** 버튼 클릭

## 기술 스택

- **GUI 프레임워크**: CustomTkinter
- **마우스/키보드 제어**: pynput, keyboard, pyautogui
- **이미지 처리**: Pillow, OpenCV
- **OCR**: pytesseract
- **패키징**: PyInstaller
- **기타**: requests (업데이트 체크)
